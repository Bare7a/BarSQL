Privacy policy

Last updated November 4, 2026

BarSQL is a desktop app that runs on your computer. It has no accounts, no analytics and no telemetry, and its developer never receives your connections, queries or data.

What BarSQL stores

Everything BarSQL keeps is in one BarSQL-data folder on your computer, next to the app or in your user folder. The guide says where.

  • connections.json holds your connections, with their database passwords, Turso auth tokens, SSH passwords and key passphrases in plain text. Keep the folder as private as the credentials in it.
  • query_history.json has the last 500 statements you ran, saved_queries.json your saved queries, editor_session.json your open tabs and their SQL, and settings.json your preferences.
  • crash.log appears if BarSQL hits a bug, mcp.log once an AI assistant uses it, and update.log when it updates itself.

None of it is sent anywhere. A crash report stays in crash.log unless you share it, for example in a GitHub issue.

What BarSQL connects to

  • Your databases and SSH hosts. BarSQL connects to the servers you set up, and to nothing else on your behalf.
  • GitHub, for updates. Release builds ask GitHub's API for the latest release at launch, and download it only when you choose to install it. GitHub sees your IP address and BarSQL's version, as the GitHub Privacy Statement describes.
  • Links. The website, GitHub and release notes links in the app open in your browser only when you click them.

AI assistants

AI apps such as Claude, Cursor or VS Code can use BarSQL as an MCP server, but only for connections where you tick Allow AI assistants (MCP). The AI app starts BarSQL on your computer and talks to it directly; BarSQL itself sends nothing to the AI's provider. The assistant sees the shared connections' names, tables and query results, never their passwords, and changes data only where you allow it. What it reads goes to its AI service, under that app's privacy policy, so share only what you'd show it. Every call is logged in mcp.log.

Downloads

BarSQL is downloaded from GitHub, under the GitHub Privacy Statement. The developer sees how many times each file was downloaded, not who downloaded it.

This website

barsql.bare7a.eu is a static site on GitHub Pages. It sets no cookies, runs no analytics and loads nothing from other sites. Your choice of light or dark stays in your browser's local storage. GitHub logs visitors' IP addresses to keep its service secure, as the GitHub Privacy Statement explains.

Your control

Your BarSQL data is all in the BarSQL-data folder: open it to see it, copy it to keep it, or delete it to remove it. Uninstalling BarSQL may leave the folder behind, so delete it yourself if you want everything gone. The developer holds none of your data, so there's nothing to request, correct or delete on that side.

Changes and contact

If BarSQL starts handling data differently, this page changes with it and gets a new date, and its history stays on GitHub. Ask questions in GitHub issues, or email bare7a@gmail.com about anything you'd rather not post publicly.
